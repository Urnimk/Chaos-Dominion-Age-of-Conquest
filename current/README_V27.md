# V27｜島嶼戰略與持續省份任務

以本次上傳的 V26 歐洲省名與不規則省界版為基底。新增可保存的中期任務，改變 AI 目標結構，因此升為 V27。

## 使用

解壓縮完整資料夾後執行「啟動遊戲.bat」。舊戰局連同世界檔、戰局 JSON／NPZ 及 Q 表 sidecar 放進 saves，可直接載入；建議保留舊資料夾作比較。V27 新存檔使用 V27_Province_Tasks 版本標籤，請用 V27 續玩。

## 四層目標

- 最終：統一世界。
- 長期：繼續沿用既有可保存島嶼戰略承諾，指定本島或海外目標島。
- 中期：針對同島可達前線，保存一個指定省份任務。任務優先考慮敵我兵力壓力、關鍵據點、已有控制率及友方接壤省區。
- 短期：沿用原戰術／Q 狀態與動作，從指定省份內合法接壤細格選擇目標。

已接入奪取省份、取得關鍵據點、清理殘餘及走廊方向任務。走廊方向是優先接壤多個友方省區的啟發式判斷，不是另加一套保證連通成功的尋路求解器。尚未登陸時，依舊執行原本建立基地／登陸／港口及拓荒階段，不虛構一個尚未可達的攻省任務。不是每個中期階段都必須強行攻省。

同一省可能存在不同國家，省份不因勝利整塊換色；軍隊、駐軍、地形及佔領仍是細格。

## 任務的持續、完成與重選

每國 province_task 保存省份地理指紋、名稱、目標國、島嶼、上層承諾 ID、開始年份、最後土地進展年份、最佳佔領格數、目前控制率、當地兵力、敵方關鍵據點與受阻原因。

達到 80% 控制、該省內沒有敵方首都／港口、敵駐軍不超過本方省內駐軍 35%，即視為取得戰略控制，不必為最後偏遠幾格永久停留。這不會刪除敵軍、改變剩餘土地歸屬或取消島嶼統一條件。

任務完成、島嶼戰略改變、前線不可達、省界重建，或 40 年沒有增加佔領格數時，才結束或重選。放棄的省份冷卻 25 年；已達戰略控制的省份不反覆建立同類任務。歷史只保留最近 100 筆，過期冷卻自動移除。兵力增加或派船不能刷新省份任務的土地進展計時；島嶼上層亦移除「單純軍隊增加算戰略進展」的條件。

## 進攻、增援與休養

可行陸戰不再一律被補給增援選項排除。既有進攻成功執行後，如果仍有合法運輸、人力與糧食資源，會另行嘗試派遣海外增援；現有艦隊與一支增援航行限制照舊。不保證每次都能同時出兵，也不憑空產生資源。

休養期間，糧食達兩年本土消耗、疲乏不超過 25%，且戰略島嶼可用駐軍達最低出兵條件時，提前結束休養並重新評估。未達條件時仍可繼續恢復。受阻訊息列出當地可用兵力、最低門檻、休養期限及疲乏；不是強迫弱軍一直進攻。

## 看哪裡

「國家查詢 → 基本狀態」增加最終目標、長期島嶼目標、中期省份任務、控制率、短期行動、受阻原因與支援狀況。表格可捲動。

國家 LOG 記錄開始、完成、取消與重選的原因。開啟 AI 診斷時，原決策記錄增加 goal_hierarchy，保存同一輪島嶼、省份任務與受阻理由。短期行動欄沿用內部動作代碼，原事件 LOG 仍會解釋執行內容。

省名、顯示省名按鈕、不規則省界、隨機地形、首都及海外首都圖示全部保留。

## 參數與效能

map_config.py：

```python
PROVINCE_TASK_CONTROL_REQUIRED = .80
PROVINCE_TASK_ENEMY_RATIO = .35
PROVINCE_TASK_STALL_YEARS = 40
PROVINCE_TASK_RETRY_YEARS = 25
PROVINCE_REST_RESUME_FOOD_YEARS = 2.0
```

任務只在既有 AI 決策時更新，從已有省區／島嶼快取及真正合法前線選擇，不每年重建地形或省界。單一任務及最多 100 筆任務歷史隨國家資料存檔。原有 Q 表維度沒有新增；高層任務是規則式策略，不宣稱已經學會完整跨層強化學習。

測試：`python -m unittest discover -v`。效能與實際運行範圍見「V27_測試報告.md」。
