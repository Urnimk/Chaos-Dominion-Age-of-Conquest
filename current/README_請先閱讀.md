# V22 海外港口策略・先行測試版

解壓縮到新資料夾，Windows 雙擊「啟動遊戲.bat」。需要 Python 3.10 以上；缺少套件時執行 `pip install -r requirements.txt`。請保留原 V21.1 資料夾作備份。

內附使用者原始第11,976年 saves，沒有替換成測試結局。載入後可接續試玩；自動存檔會寫入本資料夾的 saves。

新增海外戰區策略、付費海外港口、固定港口增援、人口與兵源成長、地方糧食帳務及撤離；取消首次登陸必勝與按年份刪除有效小島。既有 UI 結構及自動存檔保留。

State 由6維升為9維，因此升版 V22。舊6維策略Q值在唯一的獨立 `war_state_rl_brains.json` 中封存，新策略重新學習。請勿混搭不同存檔的 JSON／NPZ／Q-table。
