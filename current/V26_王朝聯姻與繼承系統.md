# V26 王朝聯姻與繼承

## 政治聯姻如何決策

每五年從有限王庭與成年王室成員挑選候選，檢查是否已有配偶、年齡、性別配對與兩代內近親；繼承本身採男女同等資格。評估國家關係、王朝關係、軍力差距、共同宿敵、距離、交戰狀態、外交能力、人格及對方繼承狀況。雙方都接受才建立婚姻。超過一定年齡仍未聯姻時，可與本國旁系結婚，避免全世界都靠跨國婚姻繁殖。

婚姻不是聯盟，也不會禁止普通戰爭。王朝宿敵關係保留，婚姻只小幅改善；沒有兵力或人口共享。

## 宣稱如何產生

政治配偶取得弱婚姻宣稱；子女出生時，對父母當時持有的王位取得強父系／母系宣稱。子女也可折減繼承父母可繼承的既有宣稱。被廢黜但仍活著的君主留下前任君主宣稱。每筆宣稱有權利人、目標國、來源、強度、建立年、到期年及可繼承旗標。

宣稱不是土地。僅持有弱婚姻宣稱不能跳過合法子女直接吞併他國。

## 繼承順位如何決定

君主死亡時一次處理其所有王位。對每國計算在世、具資格的直系子女與未過期宣稱者，依宣稱強度、地方出身、王朝延續、合法性與長幼排序。沒有候選時建立本國旁系；正常更替以和平為主。

同一個人可以在甲國順位第一、同時已是乙國國王；因此甲國繼承後，兩國真正共用同一 person_id。反之，共主死亡後兩國的地方支持可能讓不同子女勝出，和平解體。

若有兩個強候選且分數接近，記錄完整候選、來源、支持與理由。外國支持者產生王位戰爭意圖；意圖須等原有地理、兵力、糧食、運輸與 Macro 條件允許，才真的派出 Campaign，不能憑空跨海開打。過期且無可行戰役的意圖會結束，報告分開統計「提出」與「真正發動」。

## 三種政治戰爭目標

| War Goal | 勝利結果 |
|---|---|
| WAR_GOAL_SUCCESSION | 指定合法候選登基，可能形成共主或友好王朝 |
| WAR_GOAL_CLAIM_THRONE | 進取君主以既有強宣稱爭取對方王位 |
| WAR_GOAL_INDEPENDENCE_FROM_UNION | 確認獨立；敗方則可能恢復共主 |

政治戰沿用原 Campaign 的集結、實際出兵、航行、年度補給及戰鬥傷亡。結算後存活軍隊／船隻歸建，不走一般攻佔土地／首都滅國的分支。一般領土戰維持原規則。

## 診斷與保存

重大事件包含 ROYAL_MARRIAGE_PROPOSED／ACCEPTED／REJECTED、ROYAL_HEIR_BORN、CLAIM_CREATED、SUCCESSION_STARTED／RESOLVED／DISPUTED、SUCCESSION_WAR_PROPOSED／STARTED／RESOLVED。人物 ID、婚姻 ID、宣稱 ID 與戰爭 ID 可串成因果鏈。

王室人物、親屬、配偶、王位、婚姻、宣稱、邦聯、戰爭及亂數狀態完整存檔；讀檔不重抽人格或候選。歷史採有限摘要，避免 50,000 年累積整份無上限人物樹。
