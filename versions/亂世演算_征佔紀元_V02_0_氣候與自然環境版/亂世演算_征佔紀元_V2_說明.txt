亂世演算_征佔紀元 V2｜氣候與自然環境版

【定位】

V2是地圖系統第二階段：保留V1_1_1的自然海岸、半島、海灣、內海與島弧，再依緯度、海拔、距海距離、地形與隨機氣候場推導自然環境。尚未加入國家、城市、資源、人口與戰爭。

【啟動】

1. 安裝 Python 3.10 以上。
2. 安裝套件：pip install numpy pillow scipy
3. 執行「亂世演算_征佔紀元_V2_啟動.py」。

【V2新增資料層】

- 溫度（攝氏）：由緯度、海拔與局部氣候擾動決定。
- 濕度（0～1）：受海洋距離、緯度、高度與迎背風影響。
- 年降雨量（mm）：由濕度、溫度與地形雨影推導。
- 生態區：沙漠、草原、森林、雪地、凍土、沼澤。
- 湖泊：偏好濕潤、低窪、平緩且離海有一定距離的內陸。
- 河流：從高地與多雨區出發，依地勢與出水距離流向海洋或湖泊。

【UI圖層】

上方「顯示圖層」可切換：生態環境、基礎地形、溫度、濕度、降雨。

點擊地圖格子可查看座標、地形、生態、水體、溫度、濕度與年降雨量。

【全域參數】

map_config.py 保留原有地圖參數，並新增：

- LAKE_COUNT：2000×2000地圖的目標湖泊數。
- RIVER_SOURCE_COUNT：2000×2000地圖的目標河流源頭數。

小尺寸地圖會按面積縮減河湖數，避免變成水上世界。

【存檔】

所有讀寫均在 saves 資料夾：

- world_map.npz：地形、高度、陸塊、板塊、溫度、濕度、降雨、生態與水體陣列。
- world_map_preview.png：生態環境預覽圖。
- world_map_info.json：尺寸、Seed、海陸比例、氣候平均與河湖格數。

【生成原則】

同一組尺寸、風格與Seed會產生相同地形、氣候、生態與水系，方便重現測試。本模型是遊戲尺度的簡化自然推導，不是專業地球科學模擬。
