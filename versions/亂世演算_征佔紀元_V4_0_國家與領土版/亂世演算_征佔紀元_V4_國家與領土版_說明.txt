亂世演算_征佔紀元 V4｜國家與領土版

【定位】

V4是地圖系統第四階段。它保留V1～V3的地形、氣候、生態、水文與可居住性，新增靜態國家、領土、聚落及交通骨架。這一版先建立世界初始政治地圖，尚未加入人口、軍隊、外交、戰爭與動態國界。

【啟動】

1. 安裝 Python 3.10 以上。
2. 安裝：pip install numpy pillow scipy
3. 執行「亂世演算_征佔紀元_V4_啟動.py」。

【新增內容】

- 國家出生點：優先選擇建城價值、淡水和交通條件較佳的格子。
- 建國陸塊限制：過小島嶼不會生成先天無法生存的國家。
- 首都：每國一座，與出生點相同。
- 領土擴張：受首都距離、移動成本、建城價值、淡水與陸塊連通性影響。
- 無主地：極端地形、小島或超出擴張範圍的區域可以保留為無主邊疆。
- 國界：只在兩個不同國家的相鄰領土之間描線。
- 城市：從本國高建城價值的區域選擇，並與首都保持距離。
- 港口：生成於本國沿海且具一定建城價值的位置。
- 道路：在同一國家領土內連接首都、城市和港口，並參考移動成本。
- 海上航線：連接不同國家的近鄰港口，只顯示於海洋格。

【領土顯示硬規格】

國家顏色採半透明覆蓋，不會取代底層自然環境。森林、沙漠、雪地、河流與湖泊仍可辨識；國界另外以深色線條顯示。

顏色透明度由 map_config.py 的 TERRITORY_ALPHA 控制，預設0.34。

【地圖符號】

- 黃色：首都
- 白色：城市
- 青色：港口
- 棕色：道路
- 亮青色：海上航線
- 深色線：國界

【UI】

預設顯示「國家與領土」圖層，仍可切換V1～V3的所有圖層。

點擊格子可查詢：

- 國家名稱或無主地
- 是否為首都、城市或港口
- 地形、生態與水體
- 氣候及七項可居住性數值

【全域參數】

map_config.py 新增：

- COUNTRY_COUNT：2000×2000世界的目標國家數，預設32。
- COUNTRY_MIN_DISTANCE_RATIO：國家出生點最低間距。
- MIN_COUNTRY_LANDMASS_CELLS：允許建國的最低陸塊面積。
- TERRITORY_RADIUS_RATIO：領土最大擴張半徑。
- TERRITORY_ALPHA：領土半透明覆蓋程度。
- TERRITORY_CELLS_PER_CITY：領土面積與城市數量的換算。
- MAX_CITIES_PER_COUNTRY：每國城市上限。
- PORTS_PER_COUNTRY：每國港口目標數。

小地圖會依面積自動降低國家數，但最低保留8國供測試。

【存檔】

所有讀寫位於 saves：

- world_map.npz：新增territory、border、settlement、roads與sea_routes格子陣列。
- world_map_info.json：新增國家名稱、顏色、首都、城市、港口、領土面積與世界統計。
- world_map_preview.png：半透明政治地圖預覽。

V4不讀取缺少政治資料欄位的舊NPZ；遇到舊檔會重新生成。

【目前限制】

這一版領土與交通是初始世界骨架，不會隨時間改變。道路採方格近似路徑，海上航線採港口間的簡化連線；動態擴張、殖民、戰爭占領與城市成長留待後續階段。
