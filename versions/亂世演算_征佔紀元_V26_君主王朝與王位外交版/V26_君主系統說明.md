# V26 君主王朝與王位外交版

本版以這次提供的 V25_1 RAR 為基礎。君主、王室血緣、宣稱、跨國繼承及共主邦聯會進入正式存檔，屬於整數大版本更新。原有診斷寫檔與建築選址優化保留。

## 使用

1. 解壓完整資料夾，以原來方式執行「啟動遊戲.py」或 .bat。
2. 套件依賴維持 requirements.txt；沒有新增第三方執行套件。
3. 可以將原本完整 saves 資料夾複製至新版。首次載入會補建王室資料，保留舊國王姓名、王朝姓氏、任次、登基年份、原定更替年份及既有 Macro Goal。舊王在遷移以前的完整功過沒有紀錄，會標記為部分治世，不能倒推。
4. 新存檔版本為 V26_Dynastic_Politics。請保留原版存檔備份；V25_1 不支援讀取新版的王室結構。
5. 國家資訊增加人格、能力、目標、承諾、合法性、攝政、配偶、繼承人、全部王位、共主身分、宣稱與最近五任摘要。沿用現有表格，不逐年建立新控制項。

## 國王在哪裡改變 AI

| 接點 | 實際影響 |
|---|---|
| `_macro_candidates` | 對既有可行候選加上人格、志向、私人宿敵、王朝傳統與能力誤差的有界分數 |
| `_macro_update` | 在同一已承諾島嶼內，綜合守軍強度、宿敵、治世目標及王位爭議挑選政權 |
| `_macro_state_actions` | 對合法 RL 動作加入小幅偏好；不新增不可行的攻擊 |
| 登陸／戰區兵力估算 | 謹慎者要求較多優勢，冒險者略接受風險；仍保留原運輸、補給、出兵與本島生存限制 |
| 實際出兵 | 征服、野心、冒險型最多多投入既有可用兵力的 6%；親征另有 2%，永遠不超過可用兵力 |
| 登基與停滯 | CONTINUE／MODIFY／ABANDON 前任政策；保存現有戰役、航行與基地。200 年志向無進度必須重新評估 |
| 外交 | 人格與外交能力影響政治聯姻、爭取王位及長期整合 |

國王不修改士兵攻擊力、地形防禦、戰鬥亂數、人口成長或資源產量，不直接替每一格下戰術指令。最終目標始終是 WORLD_UNIFICATION。

## 人格與能力

九種人格：征服、守成、海權、拓荒、復仇、冒險、謹慎、外交、野心。各王另有兩個性格描述。軍事／海軍能力影響風險判讀與估值誤差，行政影響估值精度與補給優先，外交影響婚姻與整合，意志影響承諾。誤差由人物、目標及年代的穩定雜湊產生，重複開 UI 不會重新抽評分。

王朝保留軍事、海軍、殖民、行政或外交傳統；傳統只小幅影響一項能力及目標評分，每任人格仍獨立生成。

## 治世目標及防死鎖

支援統一本島、征服島嶼、消滅宿敵、建立海外網路、奪取敵都、軍事霸權、海軍霸權、收復失土、恢復國力、殖民擴張。候選取自現有本島、戰區、艦隊及鄰接資訊；不額外搜尋全圖找遙遠目標。

每個志向保存開始年、目標國／島、基準值、進度、最後進度年及承諾。進度依志向計算，例如新增基地、島嶼控制增加、恢復疲勞或實際奪取敵都；已有兩座基地不會每五年重複算成功。承諾限制在 0.20–0.95，評分總修正限制在 ±1.8。

無進度 200 年會記錄 KING_AMBITION_STALLED 並換一個可用志向；沒有在途戰役、且 Macro 同樣停滯時才釋放原承諾及設定短期重試冷卻。本島危局、目標死亡／成為共主伙伴及無法達成的目標優先於私人執念。休養仍受原有糧食、疲勞與恢復條件管理。

## 繼承與歷史

一般有合法繼承人時和平更替。低於 70% 合法性才可能抽取罕見的篡位、宮廷政變、繼承鬥爭或地方分離壓力。地方分離壓力只提高既有、仍須符合國力／領土與保護條件的分裂機率，沒有額外造地或強制生出叛國。

未成年君主由王室議會攝政，成年 18 歲啟用完整人格權重；若是嬰兒即位，攝政可能超過範例中的 5–15 年，以實際年齡為準。親征不加戰力；重大失敗時以低機率觸發陣亡、被俘或失蹤並處理繼承。

治世記錄包含起終人口／領土、在位年、獲地／失地、持久增益、戰績、滅國、殖民／基地、島嶼統一、排名變化、宿敵、目標完成及失都等。諡號由成果決定，不另外擲骰。舊資料無法追溯的歷史不補造。

## 開關、亂數與效能

主要參數集中在 map_config.py 的 V26 區段。King 與 succession 各自以世界 Seed／國家 ID 建立獨立亂數流；人物及完整亂數狀態存檔。初始王名也使用獨立亂數，不消耗戰鬥主亂數。

關閉 ENABLE_KING_STRATEGY_SYSTEM 時，舊戰局可走原換王流程；已經存在 V26 王室資料的戰局仍維持人物生命週期與繼承，停用策略偏好，以免凍結共主身分。另可個別關閉王朝偏好、危機、攝政、記仇、親征與王朝外交。

志向每五年檢查、婚姻每五年、共主每十年；候選每國最多六個王庭、每庭三人。所有權使用 WorldStateCache，不新增逐國全圖掃描；正式整合時才處理一次領土與資產轉移。人物保留活人及兩代祖先，歷史及過期宣稱／婚姻／戰爭定期清理。

## 長期測試額外修正

讀檔初始化使用過的島嶼所有權快取，會在覆蓋存檔地圖後清除；初始領土也隨 V26 存檔保存。建築總數則改用獨立的更新標記，不再被領土分裂檢查清除，避免連續模擬與重新讀檔的兵營數不同。
