王室年度 tick 直接計時中位數 = 0.0216 秒／100 年，占 ON 中位數約 0.06%。這只涵蓋生命週期、志向檢查、婚姻與共主更新；目標評分／出兵的少量接點耗時包含在整體計時中，不能拿 tick 比例當作全部成本。

所有權判斷共用既有 WorldStateCache；人物與宣稱用 ID 索引；候選王庭／家庭有固定上限。國王系統沒有逐國重建全圖陣列。正式王朝整合才執行一次必要的領土與資產轉移。

原有診斷 IO 與建築選址優化保留。這次的 ON／OFF 比較是在同一個 V26 引擎內切換君主系統，不是宣稱 V26 和 V25_1 遊戲軌跡相同。新遊戲王名獨立亂數、王位外交和政策本來就會改變遊戲軌跡。
