# 征佔紀元 V25_2｜區域統計與獨立畫面版

本版以這次上傳的 V25_1 為唯一基底，借鏡「細格模擬＋區域查詢＋變動更新＋獨立畫面」。屬效能與執行緒安全改善，使用底線小版本。未引入V26／V27的君主或歷史系統。

## 開啟

解壓縮後雙擊「啟動遊戲.bat」。首次執行先安裝原有依賴：`pip install -r requirements.txt`。仍使用Python＋Tkinter，不需要Unity或新增套件。原字體、視窗配置、隱藏欄位與map_config.py設定值保留。

## 本版四項調整

1. **細格保留**：地形、登陸、人口、駐軍、前線與細格領土仍是權威資料。
2. **區域查詢**：AI可重用國家×島嶼的人口、駐軍、原始產糧與島上政權；接壤國使用原接壤圖查詢。靜態島嶼索引不因領土易手重建。
3. **變動更新**：人口／士兵實際寫入後失效相應欄位及國家／島嶼；領土變更失效相關索引與區域。城市產出加成仍即時套用，沒有把舊加成凍在快取裡。
4. **獨立畫面**：單一背景執行緒負責模擬與存讀檔，另一背景執行緒負責PIL地圖轉圖。Tk只讀完成年份的獨立快照；拖曳／縮放合併重畫，表格保留原列而非全刪重建。

## 使用行為

- 畫面顯示最近已發布的完整年度；長批次中定期更新，不顯示更新到一半的國家。
- 繼續模擬時仍能拖曳、縮放、切國家與排序。底圖更新和資料更新有各自節奏。
- 儲存／讀取／匯出會排程到背景，與模擬依序執行。儲存完成會顯示實際存下的年份。
- 關閉視窗時先等待當前作業完成，再按原自動儲存設定保存，最後關閉。
- 重複讀檔／匯出請求會合併；自動存檔失敗顯示狀態，稍後再試，手動仍可重試。
- 原500年與千年地圖截圖保留。逐年模式在里程碑等候相符底圖完成後再擷取；手動長批次仍可能略過中途里程碑，與原本整批推進限制相同。

## 存檔與規則

沿用V25_1原有存檔欄位與格式標籤，快取／執行緒／畫面快照都不寫進存檔。可直接讀原存檔；保留原world_map與war_state及Q表sidecar檔案一起使用。

未修改AI狀態、動作集合、決策頻率、Q表結構、戰爭規則、海外限制或平衡參數。統計使用相同格子順序、NumPy資料型別與加總方式，避免浮點差異影響AI。

修正一項載入快取問題：建構階段的索引不得套用到讀入後不同的領土陣列；讀檔後會清空相關衍生快取。

## 測試

`python -m unittest discover -p "test_*.py" -v`

重現單一版本模擬：

`python verify_version_case.py --code . --out verification/new --years 1000 --seed 2026`

同樣命令將--code改為原V25_1資料夾、--out改為verification/old，再比較：

`python compare_version_results.py verification/old.pickle verification/new.pickle`

可加`--width 1200 --height 1200`測大型地圖，或加`--profile`輸出耗時排序。測試使用新建世界，不覆寫玩家存檔。

詳細測試、速度、快照成本與驗證限制見「V25_2_效能與驗證報告.md」。
