# V27_1｜省份選擇與出兵一致性修正版

本次為既有功能修正，使用底線版本。保留 V27 存檔格式與 Q 表狀態／動作，不新增核心系統。

解壓縮後執行「啟動遊戲.bat」。將原戰局的世界檔、war_state JSON／NPZ 與 Q 表 sidecar 一起放入 saves，可接續原本 V27 戰局；無須重新生成世界或清除 Q 表。請保留自己的原存檔備份。

## 修正

1. 選省之前檢查該省合法前線細格是否有能通過戰力門檻的進攻點。不可行的省份不建立攻省任務；現有任務失去戰力可行性時立即重評，不再只等待 40 年停滯。
2. 省份評估、進攻前檢查與實際出兵使用相同防禦估算。所有本島、外島及海戰出兵比例都必須通過安全門檻，戰術學習只從合格比例中選擇。保留原 1.10 安全倍率，沒有降低門檻或憑空增兵。
3. 省份取得戰略控制時，將相鄰省區本方兵力納入支援，且上限受本島嶼實際可投入兵力限制。仍需至少 80% 控制、沒有敵方首都／港口，且殘餘敵兵低於威脅比例。沒有刪除殘軍、轉移土地或把判定完成當成整省佔領。
4. 無可行攻擊點的任務會以原因記入歷史並冷卻。冷卻結束後仍要重新通過戰力檢查，不會只因時間到了又選回同一個打不動的目標。

不規則省界、歐洲省名與顯示開關、國徽、海外首都外框及原有 UI 均保留。

## 驗證

`python -m unittest discover -v`
