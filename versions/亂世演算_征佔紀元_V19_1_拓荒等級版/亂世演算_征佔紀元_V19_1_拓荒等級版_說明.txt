《亂世演算：征佔紀元》V19_1｜拓荒等級與地球地圖版

地圖與城市
- 新增「地球地圖」地形選項，依簡化經緯度輪廓生成大陸，保留臺灣；小型島嶼可省略。
- 地球地圖寬、高皆限制為 1200 至 2000 格，工具列可直接調整尺寸。
- 城市與首都相隔至少 60 格；兵營相隔至少 20 格。

糧食加成
- 糧食承載人口每 100,000 人提供 100% 加成。
- 人口增長與增兵速率都乘上「1 + 加成倍率」。

海外拓展與後撤
- 本島由本國控制至少 80% 且只剩本國政權後，才解鎖第一個海外名額；每一塊海外大島達 80% 且只剩本國政權，再開放一個名額。
- 一般征戰與殖民只選大島。零名額時禁止出海；危局後撤有獨立的臨時名額，遷都真正完成時才計入遠征次數。
- 後撤基礎成功率提高至約 42%，艦隊與安全港口可再提高，整體上限約 60%；敵軍逼近的港口不能出航。
- 後撤抵達小島時轉移 80% 人口、把後撤基地升為國家首都，並清除原本島上的建築與本國殘留領土。
- 海外領地若失去首都錨點，定期清除無首都的分離領土；整理不寫入歷史事件。

戰鬥與領地資訊
- 海外遠征由本國港口出發，登陸目標必須是敵方港口且在海軍作戰範圍內。
- 戰鬥佔領沿接壤前線推進；海戰從指定港口形成有限灘頭，不會直接奪取遠離前線的內陸。
- 基本狀態列出本島與各海外領地的面積、建立年份、島上人口與依人口比例分配的兵力估算，不顯示座標。

陸上拓荒
- 拓荒能力改為國家「拓荒等級」，不再建造實體拓荒站，不占用地圖格，也不提供單格防禦加成。
- 每 90 格領土提供一級目標；每次升級消耗糧食 35、木材 55、礦產 25。每級增加每次陸拓 2 格。
- 城市或兵營因間距或空位不足而不能建造時，仍會接著檢查拓荒等級升級。
- V19 舊戰局中的拓荒站會自動轉為等級，地圖標記會清除；獨立 Q 表資料可延續使用。

安裝與啟動
- 安裝 Python 3.10 以上版本，於遊戲資料夾執行 `pip install -r requirements.txt`。
- Windows 雙擊 `啟動遊戲.bat`，或執行本版啟動 `.py` 檔。
- V18、V19 與較舊相容戰局可載入；新存檔會使用 V19_1 版本標記。
