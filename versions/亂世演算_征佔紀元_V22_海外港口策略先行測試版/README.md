# 亂世演算 V21.1｜海外殖民探索修正版

此版本沿用 V21 的存檔格式和世界地圖，附上從使用者存檔續跑至第 11,976 年的狀態。

## 本版調整

- 本島統一且沒有海外據點時，動態提高殖民探索值，避免舊 Q 表的休養值永遠壓住殖民；更高價值的海戰仍可勝出。
- 戰術庫若提出休養，會回到當下合法動作和 Q 值重新比較。
- 殖民建立海外首都時指定固定後勤港；舊存檔既有海外首都也已補上港口。
- 海外增援以據點登記的固定港為目的地，不會改從其他海岸登陸。
- 存檔標示 V21.1，並保留 V21 及既有版本的讀取相容性。

## 啟動

Windows 可執行「啟動遊戲.bat」。如缺少套件，在此資料夾執行 `pip install -r requirements.txt`。

## 隨附存檔

` saves/` 內含模擬後存檔，年份 11,976，五國存活。請先備份再覆蓋自己的存檔。

詳細對照結果見 `模擬續跑報告.md`。
