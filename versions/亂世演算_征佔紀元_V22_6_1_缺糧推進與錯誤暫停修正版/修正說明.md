# V22_6_1 缺糧推進與錯誤暫停修正版

## 原因

V22_6 重構當地徵兵流程時移除了 `home` 的賦值，但本島缺糧處理仍引用它。因此糧食首次不足時會發生 `NameError: name 'home' is not defined`。
另外，自動推進失敗後只釋放 busy 標記，未停止模擬時鐘；錯誤視窗的事件迴圈會反覆派送失敗工作，導致視窗堆疊。

## 修改

- 缺糧處理先取得該國目前的本島編號，再扣減人口。
- 工作執行緒出錯即停止自動模擬、清除待推進年份。
- 錯誤通知顯示期間保持忙碌，阻止重入；關閉通知後仍維持暫停。
- 保留本次上傳版本的介面設定、外島徵兵與戰區規則；存檔格式仍相容 V22_6。

## 驗證

- 使用本次 saves(1).rar 的第 602 年存檔：舊版於第 654 年重現同一錯誤。
- 修正版由 602 年連續推進 100 年至 702 年，未再出錯，逐年人口與軍隊皆非負。
- 強制兩個不同本島國家缺糧，確認各自處理本島人口、糧食歸零。
- 模擬推進例外及彈窗內重入，確認暫停、自動推進積分清零，且僅顯示一次通知。
- Python 語法編譯通過。錯誤視窗行為以回呼測試驗證，未在此環境實際開啟 Windows 視窗。

## 使用

先關閉舊版遊戲，完整解壓縮本版後執行「啟動遊戲.bat」。
附帶 `saves/` 是你上傳的原始第 602 年存檔，逐檔保持原樣；測試的 702 年狀態沒有覆蓋它。
若只更新現有安裝，關閉遊戲後替換 `war_engine.py`、`map_viewer.py` 兩個檔案即可。
