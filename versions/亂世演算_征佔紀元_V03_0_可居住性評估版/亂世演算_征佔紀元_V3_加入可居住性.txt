亂世演算_征佔紀元 V3｜可居住性評估版

【定位】

V3是地圖系統第三階段。它保留V2的地形、氣候、生態與水文，進一步替每一格計算農業、木材、礦產、淡水、建城、防禦與移動成本。尚未建立國家、城市與人口；目前產生的是未來AI可使用的客觀環境評分。

【啟動】

1. 安裝 Python 3.10 以上。
2. 安裝：pip install numpy pillow scipy
3. 執行「亂世演算_征佔紀元_V3_啟動.py」。

【七項格子資料】

除移動成本外，其餘評分均為0～100整數；分數越高代表價值越高。

- 農業價值：溫度、降雨、地形、生態、淡水與坡度共同決定。
- 木材價值：森林與沼澤較高，並受濕度、降雨、溫度和高山限制。
- 礦產價值：山地、丘陵、板塊交界與Seed決定的地質帶較高。
- 淡水供應：河流、湖泊為100，距離增加後逐漸衰減，降雨與沼澤提供補充。
- 建城價值：綜合農業、淡水、木材、礦產、防禦、交通與氣候舒適度，並扣除洪水、沼澤與極端地形。
- 防禦價值：海拔、坡度、崎嶇地形與海岸屏障提高分數。
- 移動成本：1～20，越低越容易通行；海洋與湖泊為255，代表陸路不可通行。

【重要設計】

- 高農業價值不等於最佳城市：城市仍要考慮淡水、交通、防禦及氣候。
- 礦區不必然適合居住：高山可能礦多，但農業差、移動昂貴。
- 河流提高淡水與建城潛力，但河道本身會增加移動成本。
- 沼澤水多，卻因洪水、疾病與交通代價降低建城分數。
- 所有地質噪聲都由Seed控制；同Seed可完整重現。

【UI圖層】

除原有生態、地形、溫度、濕度與降雨外，新增：

- 農業價值
- 木材價值
- 礦產價值
- 淡水供應
- 建城價值
- 防禦價值
- 移動成本

點擊格子會同時顯示七項數值。

【存檔】

所有讀寫位於 saves：

- world_map.npz：包含V1～V3的全部格子陣列。
- world_map_preview.png：生態環境預覽。
- world_map_info.json：世界統計及六項價值平均。

V3不讀取V2以前的舊NPZ存檔；若資料欄位不足，UI會重新生成完整世界。

【效能】

評分使用NumPy uint8陣列；每個評分每格只占1位元組，避免400萬格地圖因Python物件膨脹。移動成本255保留作為不可通行標記。
