亂世演算 V23.2｜海外登陸修正版

直接使用：
1. 解壓縮整個資料夾。
2. 安裝 Python 及必要套件：pip install -r requirements.txt
3. 執行「啟動遊戲.py」或 Windows 使用「啟動遊戲.bat」。
4. 預設會載入 saves 資料夾裡的續跑存檔。

本修正版處理海外登陸卡住：軍隊登陸不再被目標島的新增居民容量錯誤限制；仍受本土留守兵力、實際人口／士兵、艦隊載量、航線與戰鬥條件限制。無可行海路／登陸方案的戰略目標會排除或中止並冷卻。

附帶續跑檢查點：從原存檔（第 29627 年，seed 444381986）推進 500 年，到第 30127 年。這是 1000 年模擬的中途檢查點，並非最終結果；1000 年模擬仍在進行。原存檔沒有被修改。

中途狀態：仍有 4 國存活；累計戰役 5418 場。即使修正登陸可行性，500 年內也尚未完成統一。
若要從此檢查點續跑模擬，可在此資料夾執行：
python headless_sanity.py --save saves --output simulation_1000y --years 1000 --resume --checkpoint-every 100

根因與修正細節請看 V23_2_根因分析.md、V23_修改說明.md。
