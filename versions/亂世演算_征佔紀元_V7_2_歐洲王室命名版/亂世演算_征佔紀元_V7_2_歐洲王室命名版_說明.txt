【V7_2 修改】
1. 王室姓名改為歐洲名字與歐洲姓氏，顯示格式為「名字．姓氏」。
2. 擴充70個歐洲名字與70個一般／王室姓氏。
3. 同一國王朝保留王室姓氏，國王更替時只重新抽選名字。
4. 分裂國家各自建立新王室姓氏，並由第1任國王重新計算。
5. 載入舊版中文國王姓名時會自動轉換為歐洲式姓名。

【V7_1 修改】
1. COUNTRY_COUNT 全域變數可直接控制開局國家數量，不再依地圖大小暗中縮放。
2. 分裂檢查改為每10年一次，且只檢查領土曾變動或正處於斷裂倒數的國家。
3. 連通區分析只處理該國領土包圍範圍，不再為每國反覆掃描整張世界。
4. 糧食、木材、礦產與領土總量加入快取；領土未變時不重複統計。
5. 已結束的遠征移出即時佇列，歷史結果仍保留於事件與戰績。
6. 地圖只在領土、建築、戰線、遷都或分裂實際變動時重新渲染。

【V7 修改】
1. 國土斷裂持續達門檻後，依主要分離方向成立東／西國家或南／北國家。
2. 首都失守時，若剩餘城市群、人口與領土達標，城市議會推舉新王並遷都；否則投降滅亡。
3. 滅亡國剩餘領土、聚落與人口清除為無主地，並鎖定死亡狀態，禁止再次重生。
4. 國家查詢顯示滅亡年份、現任或末代國王及第幾任。
5. 每國建立王室姓氏，國王約70至90年更替一次；分裂國王統由第一任重新計算。
6. 修正跨地圖接縫、滅亡國與分裂國的地圖定位；分裂國同步加入地圖國家資料與存檔。
7. 保留V6_4糧食、木材、礦產生產與既有UI配置。

【版本定位】

V6保留V1～V5的地形、氣候、可居住性、國家及空間戰爭核心，重做國家開局、領土成長與操作介面。由於國家生成及領土成長底層已改變，本次依版本規則升為V6。

【啟動】

1. 安裝Python 3.10以上。
2. 執行：pip install numpy pillow scipy
3. 執行「亂世演算_征佔紀元_V7_2_啟動.py」。

【新版UI】

- 左側：選定國家的領土、人口、士兵、艦隊、資源、建築、聯盟及戰績。
- 左下：全部國家的領土、人口及軍隊排名。
- 中央：可縮放、拖曳及點擊查詢的世界地圖。
- 右上：選定國家的專屬事件LOG。
- 右下：全世界即時戰鬥LOG。
- 地圖直接顯示國家名稱，採白字黑邊避免被地形吃掉。
- 點擊領土或左側排名即可切換查詢國家。

【時間】

- 1回合等於1年。
- 正常速度每2秒自動推進1年。
- 可暫停、繼續，或手動推進1年／10年。
- SECONDS_PER_YEAR控制每年秒數。
- AUTO_RUN_ON_START控制啟動時是否自動運行。

【國名顯示參數】

位於map_config.py：

- COUNTRY_NAME_FONT_SIZE：國名字體大小，預設12。
- COUNTRY_NAME_FONT_BOLD：是否使用粗體。
- COUNTRY_NAME_OUTLINE_WIDTH：黑色描邊寬度。

【小國開局】

- 國家不再於開局占滿大陸。
- 每國只擁有首都周圍約75～150格核心領土。
- 2000×2000預設世界的32國合計只占全圖約0.11%。
- 城市、港口、道路與其他建築不再開局免費送滿，而由國家逐步建設。

【拓荒與領土擴張】

- 只能占領與本國領土相鄰的無主陸地，不能隔空跳格。
- 預設每5年才執行一次拓荒。
- 拓荒需要士兵提供控制能力，也需糧食、木材與移民。
- 移民會從既有領土人口實際搬往新格，不會憑空生出人口。
- 建城價值、農業、淡水與移動成本會影響擴張方向。
- 和平拓荒不能直接吃掉別國領土；敵國領土只能透過戰爭占領。

【建築】

- 兵營：提高每次可擴張格數，代表駐軍及治安控制力。
- 拓荒站：優先設於邊疆，提高邊境開發能力。
- 城市：人口與行政核心，提高長期擴張效率。
- 港口：只能在控制海岸後建造；完工後建立艦隊並開放海上作戰。
- 建築會消耗糧食、木材與礦產，不會憑空出現。

【主要拓荒參數】

- INITIAL_TERRITORY_RADIUS、INITIAL_TERRITORY_MAX_CELLS：初始核心領土。
- EXPANSION_INTERVAL_YEARS：拓荒間隔年數。
- BASE_EXPANSION_CELLS：未計建築加成的基本擴張量。
- EXPANSION_CELLS_PER_SOLDIER：士兵能維持的領土上限。
- EXPANSION_FOOD_COST_PER_CELL、EXPANSION_TIMBER_COST_PER_CELL：每格拓荒成本。
- BUILDING_CHECK_INTERVAL_YEARS：建築決策週期。
- CITY_COST、BARRACKS_COST、OUTPOST_COST、PORT_COST：建築成本。

【戰爭】

仍沿用V5原則：陸戰必須接壤；海戰必須有港口、艦隊、共同可航行海域與足夠航程；距離產生集結時間與補給消耗；山地、丘陵及河流增加防守；聯盟援軍及圍剿軍必須實際行軍；占領會改變格子控制權、人口及後續資源產出。

由於各國開局相距很遠，前期通常以拓荒及建設為主，接觸國界後才逐漸進入戰爭年代。這是刻意設計，不是AI罷工。

【測試結果】

- 2000×2000正式世界：32國，初始領土75～149格，共4,573格。
- 100年後：共7,290格，約占陸地0.608%，沒有瞬間占滿大陸。
- 100年內建成16座城市、40座兵營、46座拓荒站及1座港口。
- 100年模擬約26秒，低於正常播放的200秒。
- 人口、士兵、資源非負；士兵不超過人口。
- 相同Seed、存檔重載及續跑一致性測試通過。

【存檔】

所有讀寫都位於saves資料夾。V6不讀取V6以前的戰爭存檔；地圖不符V6資料時請按「新世界」重新生成。
