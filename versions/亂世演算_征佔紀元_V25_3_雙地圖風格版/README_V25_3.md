# V25_3｜原版／羊皮紙雙地圖風格

以V25_2為基底的繪圖功能補充，因此使用底線小版本。保留細格地形、隨機世界生成、既有AI、首都／海外首都圖示、存檔格式與V25_2的背景模擬架構。

## 啟動

解壓縮後雙擊「啟動遊戲.bat」。原有存檔放入saves，維持world_map、war_state與Q表sidecar一起使用。

## 切換外觀

地圖上方新增下拉選單：**原版地形／羊皮紙地圖**。可直接切換目前世界，不需重新生成，不移動國家、首都、駐軍或任何格子。

預設值在map_config.py：

```python
MAP_VISUAL_STYLE = "PARCHMENT"  # 羊皮紙、墨線海岸、山形筆畫、淡色格線。
# MAP_VISUAL_STYLE = "CLASSIC"  # V25_2原本的詳細地形畫法。
```

介面切換只改當次顯示，不寫回設定檔或存檔。下次啟動預設由此參數決定。

```python
MAP_PARCHMENT_GRAIN = 1.0  # 紙紋強度，0關閉，建議0～1.5。
MAP_PARCHMENT_GRID = True # 淡色裝飾格線，可關閉。
```

原本的DETAILED_TERRAIN_ENABLED仍保留相容性，維持True即可；它只管原有地形生成／陰影，不再當作兩種地圖外觀的切換參數。CLASSIC指「目前的原版畫法」，不是V22_6_2舊生成流程。

## 哪些會改、哪些保留

- 羊皮紙模式改變紙張底色、國家顏色的視覺調色、海岸／國界筆觸、淡格線與山形符號。
- 國家名稱換成較適合紙張的深色墨字與淺色暈邊；字級、位置與字體設定仍沿用原本設定。
- 山形符號只出現在實際山地，不憑空生成地形。
- 首都與海外首都的形狀、色彩、外框、位置與顯示條件維持V25_2；建築底圖標記也保留原色及繪製順序。框線置於標記下方，不蓋掉地圖邊緣的首都。
- 海外航線、船隻、點擊定位及縮放座標維持原樣。
- 沒有新增省份或裝飾用假國界，國界仍對應真正領土。
- 農業／礦產／防禦／移動成本等數值圖層保留原配色，方便判讀。

風格支援國家與領土、純領土歸屬、生態環境及基礎地形圖層。世界形狀仍由上方原有的均衡／群島／隨機等選項與Seed決定，和外觀選單是兩件事。
