《亂世演算：征佔紀元》V19_2｜海外資格與危急後撤

本版以 V19_1 拓荒等級版和使用者上傳的介面為基礎。

V19_2 更新
- 本島由本國控制必須嚴格超過 80%，且本島沒有其他國家政權，才可使用一般海外征戰／殖民名額；剛好 80% 不算。
- 每次海外征戰出發前都再次驗證本島資格與階段名額，未達標不會啟航。
- 已達標且名額可用時，AI 優先發動可行的海外征戰；若沒有可承受的合法目標，則殖民合格的無人島。
- 本土剩餘少於 1,000 格、首都仍由本國控制、本島沒有城市時，可啟動緊急後撤；沿用原本小於 300 格或低於開局 25% 的危局條件。
- 國家查詢顯示本島出海資格。已用遠征次數包含失敗的征戰／殖民嘗試，和目前海外據點／名額分開計算。

原有功能
- 提供 1200 至 2000 格的地球地圖尺寸、城市與兵營間距限制、糧食承載加成。
- 拓荒站改為國家拓荒等級，不占用地圖格；舊存檔拓荒站會轉為等級。
- 一般海外征戰與殖民限合格大島，從港口出發並遵守階段名額。
- 後撤船隊可由安全港出發；抵達後轉移 80% 人口、遷移首都並清除本土殘留建築與領土。
- V19_1 與較舊相容存檔、獨立 Q 表可延續使用。

安裝與啟動
- 安裝 Python 3.10 以上版本，在遊戲資料夾執行：pip install -r requirements.txt
- Windows 雙擊「啟動遊戲.bat」，或執行本版啟動 .py。
