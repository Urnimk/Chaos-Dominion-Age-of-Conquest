# V22_4 在地存糧人口承載修正

## 規則

各島出生承載上限＝（當地年度產糧＋當地已到貨存糧÷20年）÷每人年度耗糧×90%。城市產能加成照舊計入年度產糧。

本島只計母國糧倉；外島只計該基地的supply_food，不使用母國倉庫、不計尚在海上的貨物。存糧只提高承載上限，不提高原有人口成長加成。各島仍共享同一國家成長倍率、各自累積出生小數。全國承載檢查同步納入有效基地存糧，避免被舊的純年產糧限制再次攔住。

出生速度仍為原本每島基礎10人×國家加成×休養倍率。新人口會列入當年度糧食消耗；原有缺糧懲罰與軍隊損耗保留。糧食帳務仍由年度經濟扣除一次，計算上限不另外扣糧。可調整參數為map_config.py末尾 POPULATION_STOCK_SUPPORT_YEARS = 20。

## 更新

先儲存並關閉遊戲。本包解壓到新資料夾，將目前整個 saves 資料夾複製到啟動遊戲.bat旁，再啟動。需要Python 3.10以上與requirements.txt套件。本包不含存檔，避免覆蓋玩家目前進度。

沿用V22_3全島共用人口成長、純補給日誌及拓荒修正。State／Action未改，獨立Q-table沿用；可讀V22至V22_3存檔。
