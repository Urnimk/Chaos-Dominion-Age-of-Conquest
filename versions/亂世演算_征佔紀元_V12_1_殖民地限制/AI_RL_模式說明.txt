V12.1 本島定位與殖民節奏說明

切換方式：在 map_config.py 設定 AI_MODE。
- RULE：預設模式，沿用原規則 AI 與既有殖民檢查。
- SARSA_LAMBDA：每國獨立 Expected SARSA(lambda) 大腦，決定一般戰爭行動，並在條件成立時選擇海上遠征或建立殖民地。

狀態最多四個維度：軍隊／人口比、糧食可支應年數、領土占比、最佳合法目標戰力比；每維四級。攻擊行動只包含既有合法目標且戰力比達門檻的選項，海上攻擊還會檢查航線、港口、艦隊與可用兵力。海上行動選擇偏置每次決策都會套用，包括原本已存在的 Q table 行動。

COLONIZE 只在滿足港口、最低艦隊、糧食、木材、候選海外沿岸土地及 80 年殖民冷卻條件時出現在選項中；符合條件時採用較高行動偏置。選中後沿用既有殖民程序，優先空白大陸／島嶼，並選擇建城價值較高的落點。RULE 模式不受此學習行動影響。

每國 Q 表和學習狀態只存取 saves/war_state_rl_brains.json；主戰局 JSON 不再使用 V9 的內嵌 rl_brains 欄位。V9 舊存檔若只有內嵌 Q 表，載入後各國會從空白大腦開始；沒有匹配獨立 JSON 時不會匯入舊 Q 表。

在 current 資料夾執行測試：
python -m unittest discover -s tests -v

V12：初始港口選址正式接入國家生成；取得海岸後優先建港，港口可補充艦隊。RULE 模式殖民機率提高。戰鬥守軍比例依戰區人口與附近兵營估算，山地、河流、城市、拓荒站和兵營位置影響防守，戰場隨機波動提高至 22%。

V12.1：國家地圖定位只取首都所在的地理主島，排除同國遠方殖民地；所有 AI 模式每次殖民後至少間隔 80 年，每國最多保有 6 個殖民地。
