# V26｜歐洲省名與不規則省界版

以你上傳的 V26 省區規劃與細格戰爭版為基底，將矩形省區改為不規則省份。本次依你的指定維持 V26 名稱。

## 開始使用

解壓縮完整資料夾，雙擊「啟動遊戲.bat」。需要 Python 與 requirements.txt 套件。舊存檔連同原 world_map、war_state、Q 表 sidecar 一起放進 saves；建議保留原本備份，從同一份副本做比較。

預設已開啟省區 AI。選擇地圖圖層「省區分界」即可看到規劃區塊；一般「國家與領土」不畫省界。點擊陸地，底部狀態列會顯示 P 編號、面積、該區總人口／駐軍（包含該省區所有政權）；「國家查詢 → 最近省區選擇」可看到 AI 最近一次評估幾區、選中哪些區。這是本次執行的最近紀錄，重新讀檔後等待下次選區即可更新。

## 這次實際改了什麼

1. **細格仍是真實世界。** 地形、人口、駐軍、登陸點、道路、建築、前線及佔領都保留細格。勝利不會自動整省換色。
2. **兩層查詢。** 原島嶼／戰區統計繼續提供海外宏觀目標；島內新增連通省區，提供人口、原始產糧、兵力、政權、建築數與相鄰省區。
3. **AI 先選區再選格。** 陸上進攻先按附近敵我駐軍壓力、建城價值、戰術目標距離比較前線省區，最多選三區，再沿用原本戰術評分與最多 96 格取樣選出真正攻擊點。包圍首都、收復港口仍保留各自距離偏好。
4. **變更才失效。** 人口／兵力寫入時讓對應省區欄位失效；已知整國批次則讓該國相關快取失效。領土變更讓受影響島嶼內的省區及前線快取失效；未知範圍採保守清除。重算都在下次查詢時進行。建築數直接查詢該小區塊，避免建築改動後沿用舊值。
5. **畫面持續回應。** 保留 V25_2 起的單一模擬寫入工作執行緒、獨立底圖工作執行緒與完成年份快照。畫面不讀取正在修改的動態陣列；省區快取也不與模擬執行緒共用。

本版省份改為**不規則、沿地形延伸的規劃區域**，參考行政省份的自然輪廓感，不複製中國實際省界。

- 依各連通陸塊面積安排分散起始點，使用該世界 Seed 的獨立亂數，沒有規則方格省界。
- 沿實際陸地計算最短阻力路徑。平滑變化的區域阻力讓省界自然彎曲；山地、高差與跨越河流增加阻力，會影響省份成形，但不保證每條省界都與山脊或河流重合。
- 不跨海連成一省，不混合不同島嶼；不連通的片段會拆開，過小的岸邊碎片盡量合併到同島相鄰省份。獨立小島可以保留單省。
- 省界固定，不會隨國家戰爭每年重劃；同一省內仍可能同時存在多國前線。

省份只是原有規劃層，沒有新增省長、整省佔領或省級經濟。

海外仍沿用「島嶼／戰區選擇 → 原登陸檢查與細格選點」；新省區評分用在上岸後及本島陸戰。海外首都／首都距離限制、遠征冷卻、登陸安全檢查均沿用原規則。

## 比較開關

map_config.py：

```python
PROVINCE_STRATEGY_ENABLED = True  # False：回到 V25_3 陸戰選格流程
PROVINCE_SIDE_CELLS = 32          # 目標平均面積約為 32² 格，不是矩形邊長
PROVINCE_BOUNDARY_ROUGHNESS = 1.0 # 省界彎曲程度，建議 0.5～1.5
PROVINCE_TERRAIN_INFLUENCE = 1.0  # 山地、高差、河流對劃界的影響
PROVINCE_FRONT_CANDIDATES = 3     # 每次保留最多幾個前線省區
PROVINCE_PRESSURE_WEIGHT = 1.0
PROVINCE_VALUE_WEIGHT = 0.15
PROVINCE_DISTANCE_WEIGHT = 0.5
```

更改後重新啟動；從相同存檔或相同 Seed 分別測試。AI 會改選目標，後續領土與勝負不同是預期結果，不適合把不同戰局的耗時直接當成純計算加速率。False 時仍可使用省區分界圖層及點擊查詢。

```python
MAP_VISUAL_STYLE = "PARCHMENT"  # 原有羊皮紙／CLASSIC 開關保留
MAP_PARCHMENT_GRID = False     # 預設隱藏裝飾格線；真實省區分界另由圖層顯示
```

地形依原 Seed 隨機生成。首都、海外首都國徽、亮藍外框及國名顯示條件沿用 V25_3；省界不覆蓋原建築標記的完整像素範圍。省區編號僅是查詢 ID，不取代島嶼名稱；每省另有歐洲風格的專屬省名。

## 存檔與診斷

省界仍是可重建衍生資料，不改 Q 狀態或動作；省名以可選的 province_names 字典存入既有 JSON。舊存檔缺少這個欄位時會自動補名，既有格式標籤保留。省區大小及 AI 開關由設定檔控制，不會自動寫入舊存檔；重現測試時要一併保留設定。

開啟 AI 診斷時，同一筆 AI 決策的 `province_selection` 包含選區、排名分數與規則；效能診斷新增 `province_front_selections`、`province_front_candidates` 計數。沒有額外逐年省區檔案。前線 pair 快取最多 128 筆，最近選區僅保留每國一筆。

## 歐洲風格省名與顯示開關

每個省份都有唯一省名，以歐洲語感的中文音譯詞根組合，例如堡、海姆、福特、貝格、維克等，統一加「省」。名稱採本世界 Seed 與省份地理指紋產生，不使用戰爭 AI 亂數。

地圖上方「顯示島名」右側新增 **顯示省名** 按鈕，按下後切為「隱藏省名」。與島名開關獨立，任何地圖圖層都可使用；只重畫文字覆蓋層，不重算地形或省界。預設關閉，視窗再次啟動後重新切換即可。

縮小時會略過太小、畫面外或相互重疊的標籤，也會保留首都／海外首都及國名周圍空間；放大後可顯示更多。地圖沒有同時印出所有省名，並不代表該省沒有名字：點擊省份仍會在底部顯示省名與 P 編號。「最近省區選擇」也改用省名呈現。

省名與國家分開：改變領土歸屬、國王或王朝不會重新命名；名稱隨戰局儲存、讀取。若更改省區大小或劃分參數，形成不同省界的區域將取得新名字；只有地理形狀完全相同的區域才能沿用原有名稱，避免把舊省名錯套到不同的新省份。
