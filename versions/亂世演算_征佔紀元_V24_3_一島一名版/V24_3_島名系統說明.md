# V24.3 一島一名版

V24.3 一島一名版

以本次上傳的V24.2 RAR為基底，繼承原地名系統的所有名稱查詢入口。

【名稱規則】
每個既有 continent／島嶼編號只有一個島名，不再依海岸、平原、山地、河湖切成不同地名。
名稱結尾採「島、嶼、海岸、大島」，例如晨曦島、碧玉嶼、銀月海岸。
不同島名稱不重複；同島多國、殖民或易主都不改名。海域只顯示「海域」。
島嶼辨識沿用原有陸塊編號，不改地形、領土、戰略目標或物流規則。

【繼承與存檔】
舊存檔讀入時，優先取每座島上面積最大的舊地名，替換地形後綴為島名後綴。
新存檔保存 islands、island_name_aliases、island_naming_version。
舊 geographic_name_at、geographic_regions、geographic_region_id 等入口繼續可用，由島名系統提供資料。
原始歷史事件不改寫；顯示時把旧地名、島編號／陸塊編號轉成島名，並保留綠色定位連結。
若一個舊地名跨越多島，以重疊面積最大的島建立別名對應，不憑事件文字臆測位置。
命名不消耗遊戲亂數；存檔重載後島名穩定。島名標籤／定位點保證在對應島嶼的土地上。
地圖按鈕、領地欄、提示與戰略目標文字改用島名；快照仍使用原快照流程。

【保留本次來源設定】
海外失敗禁征50,000年；登陸最小距離100格（上傳檔已改為100，本次保留）。
千年地圖快照與其餘使用者自訂設定保留。

【使用】
解壓到新資料夾，先備份再複製目前完整saves資料夾進來，執行「啟動遊戲.bat」。
本包不附存檔；新版存檔請使用本版或後續相容版本開啟。

既有baseline100測試存檔遷移：60座島得到60個不同名稱、282個舊地名別名。
存檔重載後名稱、別名、RNG一致；1年headless與cache consistency通過。
