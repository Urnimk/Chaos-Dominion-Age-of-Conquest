# V24 — 增量模擬核心版

- 以 profiler 驗證後，加入不落盤的 `WorldStateCache`：快取每陸塊所有權摘要與各國控制陸塊，減少戰略評估重複掃描全圖。
- 每次 AI 戰略決策建立短命 `StrategicSnapshot`，在 hierarchical／overseas strategy 共用人口、駐軍、受控陸塊、合法目標及戰區查詢；不寫入存檔。
- 領土 invalidation 細分到國家／國家×陸塊；已盤點的攻佔、殖民、拓荒、撤退、分裂與飛地清理傳入受影響陸塊，未知範圍仍保留安全的全域清除。
- `_spatial_indices` 改為國家×陸塊版本化快取，異島未受影響的索引保留。
- 海路 A* 保持原 heuristic、候選順序、成本與 heap tie order，內嵌等價鄰居列舉；路徑 cache 加上 navigation epoch key 與 4096 項 LRU 上限。
- 保留 V23.2 海外登陸、港口、殖民、補給、增援、Macro Goal、AI 決策頻率與 Q-table 行為。V23.2 存檔可載入，V24 存檔用新版本標記。
- 同一存檔與 Seed 跑 100 年：V23.2 166.95 秒，V24 85.49 秒，完整動態狀態完全等價。

## 行為變更

- 海外進攻不再要求駐軍大於全島所有敵軍總和。逐戰術、逐目標檢查實際預估守軍、地形、士氣、可投入兵力、留守兵力、休養期與同時出征上限。評估戰力須達預估防守的110%；仍可能因戰術、行軍期間變化及戰鬥隨機性戰敗。
- 有可行進攻／拓荒／殖民選項時，其 Q+偏好評分至少高於其他行動0.8；停滯60年後為1.6。沿用原探索率與Q學習，不指定任何國家必勝。
- 停滯探索加分排除守港、守首都。防守／等待期間無領土增加且無勝戰時，學習回報扣0.15；仍允許必要防守。
- 和平但未平定的外島可主動、付費拓荒。無可遷移平民時，有限解甲當地士兵成為拓荒居民，保留最低駐軍；不增加人口，不跨海瞬移。
- 行動失敗改為翌年重試。補齊戰區行動的失敗後備執行分支。
- 每次決策日誌記錄動作、執行成功與否、戰略條件及下次決策年份。動作代碼保留供查核。
- 修正啟動批次檔所指主程式缺檔問題。
- 保留原有島嶼承載、本島出海人口上限、地方糧倉、休養三倍產糧與嚴格撤離規則。
- 狀態維度及Q表格式不變，可讀取舊存檔；新版存檔標記為V22_6_6。
