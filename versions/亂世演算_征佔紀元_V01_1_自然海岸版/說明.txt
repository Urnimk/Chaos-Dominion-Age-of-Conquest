亂世演算_征佔紀元 V1_1｜自然海岸版

【定位】

這是地圖系統五階段中的第一階段，只負責生成與檢視自然地形，尚未連接國家、人口、資源、城市、國界、戰爭或強化學習。

【啟動】

1. 安裝 Python 3.10 以上版本。
2. 安裝套件：pip install numpy pillow scipy
3. 執行「亂世演算_征佔紀元_V1_1_啟動.py」。

【已有功能】

- 預設 2000×2000 正方形格，寬高可調。
- 可指定 Seed；相同設定與 Seed 會生成相同世界。
- 六種世界風格：均衡、超級大陸、群島、破碎大陸、內海、雙大陸。
- RANDOM 模式會依 Seed 穩定選擇一種風格。
- 大陸核心、多尺度海岸、Domain Warping、島鏈、板塊邊界山系。
- 大陸具有隨機長軸與方向，降低近圓形陸塊。
- 半島由逐漸縮小的連續地塊延伸，不是單一圓點。
- 海灣由外緣向陸地侵入；內海則生成在大陸腹地。
- 島鏈沿弧線方向排列，具有大小與間距變化。
- 自動依目標海洋比例反推海平面。
- 清除過小碎斑，但保留合理島嶼。
- 地形：深海、淺海、海灘、平原、丘陵、山地、高山。
- 地圖縮放、拖曳及單格查詢。
- 可查座標、高度、地形、陸塊編號及板塊編號。

【全域參數】

全部集中於 map_config.py，包括：

- MAP_WIDTH / MAP_HEIGHT：地圖尺寸。
- MAP_SEED：預設 Seed。
- WORLD_STYLE：預設世界風格。
- TARGET_OCEAN_RATIO：目標海洋比例。
- CONTINENT_CORE_MIN / MAX：大陸核心數。
- MIN_ISLAND_AREA：最小保留島嶼面積。
- TECTONIC_PLATE_MIN / MAX：板塊數量。
- MOUNTAIN_STRENGTH / WIDTH：山脈強度與寬度。

【存檔】

所有生成及讀取檔案都位於程式旁的 saves 資料夾：

- world_map.npz：高度、地形、陸塊及板塊陣列。
- world_map_preview.png：世界預覽圖。
- world_map_info.json：Seed、尺寸、海陸比例與生成資訊。

【效能設計】

地圖不使用每格 Python 字典，而是使用 NumPy 緊密陣列。2000×2000 地圖約有 400 萬格，仍能維持合理記憶體。UI也不建立400萬個Canvas物件，而是顯示裁切後的地圖影像。

【下一階段暫不實作】

氣候、溫度、濕度、森林、沙漠、雪地、河流、湖泊，留待第二階段。

【V1_1 相較 V1】

V1 已能穩定生成世界，但陸塊容易偏圓。V1_1 只改良自然地理形狀，不加入國家、資源或戰爭系統，因此仍屬於第一階段。
