## 觀察範圍與限制

兩個種子只能提供有限樣本。共主數量的峰值、建立／解體次數已如實列出，不能以單次世界結果證明所有地圖永遠平衡。長期整合與低忠誠獨立若自然樣本為零，表示本次沒有觀察到，不能宣稱已自然發生；整合階段、低忠誠獨立與實際資產保存另由明確受控測試覆蓋。真實存檔若仍有七國並存，亦不能稱為已消除所有戰局僵持；需結合現有物流與停滯診斷判斷。
